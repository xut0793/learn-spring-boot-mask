# 附录 C · 术语表

按第一次出现的章节排序。正文里这些词始终是这个意思。

| 术语 | 含义 | 章节 |
| --- | --- | --- |
| 脱敏 / 打码 | 把敏感字符串改成保留部分原文、其余用掩码字符替换的形态。本教程默认掩码是 `*` | 1 |
| 加密 | 用密钥可还原的变换。和脱敏不同：密文不是给人扫一眼的，脱敏结果通常仍像「残缺的原文」 | 1、14 |
| 哈希 | 单向摘要，不能还原成原文。密码存储用哈希，不用脱敏 | 1 |
| 静态脱敏 | 在库里或出库文件里一次性改掉明文 | 1 |
| 动态脱敏 | 库中仍是明文，只在出站（HTTP / 日志 / 查询结果）时改 | 1 |
| 出口通道 | 不改 Java 对象，只改写出的字节。Jackson、Logback | 2 |
| 突变通道 | 把对象或查询结果里的明文就地换成打码值。AOP、MyBatis | 2 |
| 通道 | 一个框架扩展点上的脱敏入口。四个：Jackson / Logback / AOP / MyBatis | 2、9~12 |
| 策略 | `MaskStrategy`：某种类型怎么打码、怎么判断已经打过 | 4 |
| 规则 | `MaskRule`：某类型保留几位、用什么字符、开不开。策略是算法，规则是参数 | 4、7 |
| 引擎 | `MaskEngine.apply`：所有通道共用的唯一入口，八步判定 | 6 |
| 旁路 | `shouldBypass()` 为真时原样返回明文。默认 ADMIN | 5 |
| 还原 / 解敏 | 授权角色从库中再取明文。不是把星号算回去。AES 令牌可选，见第 14 章线程 B | 5、14 |
| 幂等 | 对已经是当前规则打码形态的值再 `apply`，应 SKIP，不再套一层 | 4、6 |
| 角色上下文 | 本次请求的 `MaskRole`，来自 Security 或调试 Header，存在 ThreadLocal | 5 |
| 规则版本 | `ruleVersion`：规则变更后自增，缓存 key 带上它，旧结果自然不可达 | 7 |
| 热更新 | 不重启进程改内存中的规则/开关。不是改磁盘上的 YAML | 7 |
| 可逆脱敏 | 展示仍打码；另开还原接口。闭环是鉴权 + 查库（线程 A）。AES 用于限时票据：弹层刷新、点拨外呼（线程 B），票面 ≠ 手机号 | 14 |
| fail-open | 组件没准备好时放行明文。静态桥未 bind 时的行为 | 9、18 |
| fail-loud / fail-closed | 出错就抛或拒绝写明文，不装成成功 | 6 |
| 精确断言 | 测试必须写期望的那一串星号，而不是 `isNotEqualTo(明文)` | 15 |
| optional 依赖 | starter 编译需要、不传递给使用方。通道框架都是这样 | 18 |

不要混用的几对：

- **打码值 vs 密文**：`138****5678` 是打码；Base64(IV+GCM) 是密文。接口默认只出前者。
- **关通道 vs 关总开关**：`channels.jackson=false` 只让 Jackson 透传；`enabled=false` 引擎对所有通道空转。
- **跳过 vs 旁路**：SKIP 是「已经打过或规则关了」；BYPASS 是「这人可以看明文」。指标标签不同。
